# Bundled Tor

These binaries come from the official Tor Expert Bundle distributed by the Tor Project.

Source page: https://www.torproject.org/download/tor/

Included bundles:

- `darwin-arm64`: Tor Expert Bundle 15.0.14, tor 0.4.9.8
- `darwin-x64`: Tor Expert Bundle 15.0.14, tor 0.4.9.8
- `win32-ia32`: Tor Expert Bundle 15.0.14, tor 0.4.9.8
- `win32-x64`: Tor Expert Bundle 15.0.14, tor 0.4.9.8
- `linux-ia32`: Tor Expert Bundle 15.0.14, tor 0.4.9.8
- `linux-x64`: Tor Expert Bundle 15.0.14, tor 0.4.9.8
- `linux-arm64`: Tor Expert Bundle 16.0a6, tor 0.4.9.7

The Linux arm64 expert bundle was only available as alpha on the Tor download page at the time it was added.
